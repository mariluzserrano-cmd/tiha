02 · Construye con propósito

Tu arquitectura CARGA

C Contexto¿Quién necesita qué y en qué situación?

Sitúa la necesidad: rol de apoyo, destinatario y situación. Aquí comienzan la empatía y la personalización.

A Acción¿Qué resultado concreto necesitas?

Comienza con un verbo: redacta, resume, compara, organiza, traduce o revisa. Define qué debe entregar la IA.

R Reglas¿Qué debe respetar el resultado?

Define tono, idioma, formato y límites. Las reglas generales piden conservar los hechos y preguntar cuando falten datos.

G Grounding¿En qué información debe apoyarse?

Grounding significa dar una base al resultado. Pega información autorizada y anonimizada: hechos, un fragmento de documento o el mensaje que necesitas trabajar.

Escribir un enlace o el nombre de un archivo no incorpora su contenido. Esta aplicación no abre documentos ni consulta fuentes externas.

A Auditoría humana¿Quién revisará y qué comprobará?

Planifica la revisión antes de pedir el resultado. Esta parte del prompt no significa que la revisión ya ocurrió.

Conserva tu trabajo

El guardado es voluntario y se limita a este navegador. Exportar el borrador permite llevarlo a otro dispositivo.

No se guarda automáticamente la respuesta que pegues para auditar. La persistencia de archivos locales depende del navegador.

    Elemento del promptUbicación en CARGA
    Rol, destinatario y situaciónC · Contexto
    Tarea y resultado esperadoA · Acción
    Tono, formato y límitesR · Reglas
    Información y fuentes autorizadasG · Grounding
    Responsable y criterios de revisiónA · Auditoría humana
    Comunicación efectiva: una revisión breve
    • Asunto específico: que permita reconocer el propósito del correo.
    • Idea principal al principio: explica qué ocurre o qué necesitas.
    • Hechos reconocibles: incluye fechas, unidades y referencias verificadas.
    • Acción clara: indica qué se solicita y el plazo, si está confirmado.
    • Tono humano: reconoce el impacto y conserva una voz respetuosa.
    • Canal adecuado: considera si necesitas un correo formal, una coordinación breve o una conversación directa.
    Literacia digital: preguntas antes de copiar y pegar
    • Fuente: ¿quién produjo esta información y de cuándo es?
    • Vigencia: ¿estoy usando el procedimiento o documento correcto?
    • Evidencia: ¿la respuesta distingue datos de suposiciones?
    • Privacidad: ¿puedo sustituir nombres y referencias por marcadores?
    • Claridad: ¿hay pasos comprensibles, fechas completas y enlaces descriptivos?
    • Mensajes sospechosos: verifica solicitudes inusuales por un canal conocido; una revisión de texto no demuestra que un enlace o archivo sea seguro.
    • Responsabilidad: ¿qué debo cotejar personalmente antes de actuar?
    Práctica breve para el taller
    1. Aplica “Comunicar un retraso” y completa sus marcadores con datos ficticios.
    2. Cambia el destinatario y el tono. Observa qué partes del prompt se modifican.
    3. Solicita tres alternativas en tu IA y compara si conservan los mismos hechos.
    4. Pega una respuesta en Auditoría humana y registra tu revisión.

    Cómo publicarla en GitHub y utilizarla sin conexión
    1. Descarga el archivo carga-tiha-allied.html.
    2. Súbelo a la carpeta principal de tu repositorio tiha, que ya utiliza GitHub Pages.
    3. Abre la dirección publicada y confirma que carga correctamente.
    4. Pega esa dirección en el generador de QR.

    Para trabajar sin internet, abre el HTML descargado en un navegador que permita ejecutar archivos locales. Abrir el enlace una vez no garantiza que quede disponible sin conexión.

    En celulares, el manejo de HTML descargado varía. Si el dispositivo solo muestra una vista previa del archivo, prueba otro navegador o utiliza el enlace publicado con internet. Esta versión no instala una aplicación móvil.

    Un QR para tu dirección publicada

    El enlace sugerido funcionará después de subir el HTML con ese nombre. El QR se genera localmente; no comprueba si la página ya existe.

    Usa una dirección corta: hasta 106 caracteres ASCII. Prueba el QR con la cámara del celular antes de enviarlo al grupo.
